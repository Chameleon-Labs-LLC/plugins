# docs-toolkit

Generate and maintain project documentation — project-documenter (user-facing feature docs + sitemap), technical-documenter (developer/API docs), feature-documenter (feature inventory), update-code-map (navigable CodeMap.md with verified line numbers; spec bundled), and raginclude-generator (.raginclude files for RAG indexing).

## Skills

- **feature-documenter** — Analyzes a codebase and generates comprehensive user-facing feature documentation.
- **project-documenter** — Generate user-facing feature documentation, Google sitemap, and navigational site map for any project.
- **raginclude-generator** — Generate a .raginclude file for any project to feed its RAG knowledge base.
- **technical-documenter** — Generate developer and support-staff documentation for any project.
- **update-code-map** — Use when users ask to update or create the code map / CodeMap.md, refresh documentation line numbers, document new files, or when Docs/CodeMap.md is missing or older than 7 days.
