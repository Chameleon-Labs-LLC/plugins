# graphify

Turn any folder of files — code, docs, papers, images — into a navigable knowledge graph with community detection: interactive HTML, GraphRAG-ready JSON, and a plain-language audit report.

## Skills

- **graphify** — any input (code, docs, papers, images) - knowledge graph - clustered communities - HTML + JSON + audit report.

## Install

```
/plugin marketplace add Chameleon-Labs-LLC/plugins
/plugin install graphify@chameleon-labs
```
